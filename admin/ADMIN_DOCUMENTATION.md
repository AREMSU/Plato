# Plato Standalone Admin Dashboard

A robust, premium admin console built in **React Native** for managing the Plato meal-sharing platform. The admin dashboard communicates entirely via a secure Django JSON REST API, maintaining a strict decoupled structure.

---

## 🌟 What the Admin Dashboard Can Do

The Plato Admin Dashboard is divided into **five feature-rich management centers**:

### 1. 📊 Interactive Dashboard Hub
*   **Real-time Analytics:** Instantly view active metrics such as Total Revenue, Monthly Earnings, active vs. cancelled portion counts, total registered users, and active meal listings.
*   **Visual Distributions:** Interactive visual breakdown of listed meal categories (e.g., Veg, Non-Veg, Bakery, Dessert).
*   **Recent Activity Streams:** Dedicated feeds that display recent bookings, new user sign-ups, and recently created meals.
*   **Pull-to-Refresh:** Swipe down to instantly query the REST API for updated real-time analytics.

### 2. 👥 User Management Center
*   **Deep Search & Filters:** Search users instantly by name, email, or university, or filter by account type (Active, Inactive, Staff).
*   **Profile Dossier:** View individual profiles displaying host rating, biographical info, university affiliation, active meal listings, and booking history.
*   **Administrative Powers:**
    *   **Toggle Account Status:** Instantly suspend or reactivate any user.
    *   **Staff Promotion:** Promote standard accounts to staff/admin role or revoke access with one tap.
    *   **Account Deletion:** Cleanly delete spam or violating accounts.

### 3. 🍛 Meal Registry & Moderation
*   **Moderation Filtering:** Filter meals by categories, vegetarian status, featured items, available portions, and sold-out listings.
*   **Feature Control:** Feature standard host meals to highlight them directly on the buyer app homepage, or unfeature them.
*   **Violation Removal:** Delete meal listings that violate platform standards.

### 4. 📋 Booking & Transaction Center
*   **Order Tracking:** View confirmed and cancelled meal portions, pricing, transaction reference logs, and active status.
*   **Force Cancellation:** Cancel problematic orders on behalf of hosts or buyers, which automatically returns the purchased portions back to the host's active stock.

### 5. 💎 Subscription Tracking
*   **Paid Account Log:** Track subscribers enrolled in Plato Pro or standard tiers.
*   **Transaction Logs:** View transaction amounts, start dates, automatic expiry dates, and actual days remaining.

### 6. 🔐 OTP Log (Security Log)
*   **passcode Auditing:** View every single one-time passcode generated by the platform, tracking code usage and expirations to inspect authentication health.

## 🛠️ Developer Setup & Launch

### 1. Start the Django REST API Backend
From the main `plato` workspace:
```bash
/home/k_suraj/plato/venv/bin/python manage.py runserver 0.0.0.0:8000
```

Go to the `admin/` folder and launch the Metro Bundler:

*   Press **`a`** to launch on an Android Emulator.
*   Scan the QR code with **Expo Go** on a physical phone.

## 🌐 Network & Troubleshooting: `Network request failed`

If the mobile app shows a network failure:

1.  **Same Wi-Fi Network:** If testing on a physical phone, ensure both your computer and your phone are connected to the **exact same Wi-Fi network**.
2.  **Firewall Blocks:** Your Linux firewall might be blocking incoming traffic on port `8000`. You can allow it temporarily using:
    ```bash
    sudo ufw allow 8000/tcp
    ```
3.  **Automatic Fallbacks:** The admin client features an automatic IP fallback engine that tests:
    *   `192.168.1.7:8000` (Local Network)
    *   `10.0.2.2:8000` (Android Emulator Loopback)
    *   `127.0.0.1:8000` / `localhost:8000`
